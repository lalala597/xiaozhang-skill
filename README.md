# 小张Skill

一套认知差值探测管线。**目的不是吸收知识，是找到实现目标的更短路径。**

大部分知识工具帮你过滤已知的东西。这套的核心规则相反：

> 「已知」不该被过滤，只有「已知且一致」才该过滤。
> **「已知但相反」——你有一个判断，对标者有一个完全不同的判断——恰恰应该放到最高优先级。**

## 四个工具，一条管线

每一步的输出是下一步的输入。

| 步骤 | 工具 | 做什么 |
|---|---|---|
| 1 | `xiaozhang-goal` 目标翻译器 | 把模糊愿望翻译成一句能当裁判用的目标 |
| 2 | `xiaozhang-belief` 信念状态库 | 记录你在具体问题上现在相信什么 |
| 3 | `xiaozhang-benchmark` 对标定位器 | 找到你能像素级观察其决策过程的样本 |
| 4 | `xiaozhang-absorb` 认知差值探测器 | 找你和对标者的判断差值，挖双方前提 |

### 为什么第二步最关键

常见做法是把项目和目标丢给 AI 让它「了解你」。这解决不了核心问题：

**目标只说明你要去哪里，不说明你现在怎么理解一个概念。**

而认知差值来自后者。一段材料让你停下来，通常是因为「我原来相信 A，它说 B」。AI 只知道你的目标，就只能猜你的旧认识——猜错了，产出的不是差值，是一份看起来贴着你的通用建议。

## 每个工具都有安全阀

前置条件没准备好时，它们不会硬跑：

- 目标还在空转 → 不进后面的管线
- 你在某个问题上没有答案 → 写 `UNKNOWN`，不替你编一个
- 信念库不够用 → 停下来告诉你哪里是空的，不假装了解你

**编出来的信念会让整条管线产出假冲突。诚实的空位比编造的答案有用一百倍。**

## 安装

支持 Claude Code、Codex、豆包、Trae 等支持 Skills 的 Agent。

```bash
git clone https://github.com/lalala597/xiaozhang-skill.git
```

把 `skills/` 下的目录复制或软链到你的 Agent skill 目录：

```bash
# Claude Code
cp -r skills/* ~/.claude/skills/

# Codex
cp -r skills/* ~/.codex/skills/

# 通用 Agents（豆包 Mac App / Trae 等）
cp -r skills/* ~/.agents/skills/
```

## 怎么开始

不知道从哪开始，就从第一步开始：

```
/xiaozhang-goal
```

它会追问你，直到你的目标能当裁判用为止。目标清楚了，后面三步才有判断依据。
