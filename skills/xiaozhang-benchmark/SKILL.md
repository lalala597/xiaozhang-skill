# 小张Skill · 对标定位器

帮用户找到值得拆解的对标，并锁定拆解的颗粒度。

## 一句话立场

**靠得近提高的是可观察度，不是真理权重。**

你继续看某个人的理由，不该是「他更接近真理」，而该是「他的决策过程对我更可见」。这两者混淆，会让人把对标当导师，把模仿当信仰。

对标不是偶像，是**高分辨率决策样本**。

## 五重过滤

按顺序过。前一层没过，不进下一层。

### 1. 可观察度

他的**决策过程**能不能被你看到？不是结果，是过程。

- 能看到「问题—判断—动作—结果—修正」的完整链条 → 通过
- 只能看到结果（他很成功、粉丝很多）→ 不通过

只有结果没有过程的人，不能当对标。你无法从结果反推路径，那样学到的是幸存者偏差。

### 2. 资料可得性

- 他的资料你能不能持续、低成本地拿到？
- 是否有足够体量做纵向对比（同一个问题他在不同时间怎么说）？

拿不到资料的对标，再好也没用。

### 3. 路径可达性

他现在的位置，是否可以从你现在的位置到达？

关键不是差距大小，是**起点条件是否可复制**。他的成功里有多少来自你没有的东西——平台红利、既有资源、时间窗口、身份？

这一层不是让你排除强者，是让你在下一步知道要过滤掉什么。

### 4. 目标同向性

他在往哪走？和你 `xiaozhang-goal` 翻译出来的目标是否同向？

- 同向 → 他的取舍对你有参考价值
- 不同向 → 他的方法可能正确，但服务于一个你不想去的地方

**这一层必须用翻译过的目标来判，不能用愿望级目标。**

### 5. 冲突可能性

这是本 skill 和普通对标分析最大的区别。

问：**你和他在具体问题上，有没有明确不同的判断？**

- 有 → 高价值对标。差值来自冲突，一个你完全同意的人给不了你差值。
- 完全没有 → 要么你还不了解他，要么他对你只是复述器。

> 一个「你从头到尾都同意」的对标，学习收益接近零。真正值钱的是那些你能说出「这一点我不这么认为」的人。

## 输出

```markdown
## 候选对标
| 人 | 可观察度 | 资料可得 | 路径可达 | 目标同向 | 已知冲突点 |

## 选定
{一个，不要多个}

## 为什么是他
{一句话，必须落在可观察度上，不能落在「他很厉害」}

## 拆解颗粒度
应该拆什么：{问题—判断—动作—结果—修正 链条 / 具体方法 / 取舍规则}
不该拆什么：{他的普遍性结论、金句、价值观宣言}

## 需要过滤的不可复制条件
{他的起点、资源、时机、平台红利、既有受众}

## 已知冲突点（喂给差值检测）
{你和他判断不同的具体问题，逐条列}
```

## 边界

- **一次只选一个对标。** 同时对标三个人，冲突信号会互相抵消，无法归因。
- **不拆他的结论，拆他的决策链。** 结论受他的特殊条件影响，决策链才可迁移。
- **对标不是导师。** 本 skill 不产出「他说得对所以你要照做」，只产出可拆解的样本和已知冲突点。
- **定期复核。** 对标的价值会随你的位置变化而衰减。你已经走到他附近时，他的可观察度优势就消失了。

## 交接

选定后，把「拆解颗粒度」和「已知冲突点」两段直接喂给 `xiaozhang-absorb`，它会在这个基础上做认知差值检测。
